    Database Schema¶

    The AI Project Manager system stores project, workspace, and communication data in a relational database.

    The database schema is designed to support:

    • Project and workspace management
    • Slack channel integration
    • Communication intelligence
    • Message storage and analysis

    Users Table¶

    Stores information about system users such as administrators, developers, and freelancers.

    Column Name Data Type Description
    user_id UUID (PK) Unique identifier for the user
    slack_id UUID (PK) Unique identifier for the user
    name VARCHAR Full name of the user
    email VARCHAR User email address
    role VARCHAR Role (Admin, Developer, Freelancer)
    created_at TIMESTAMP User creation time

    Workspace Table¶

    Represents Slack workspaces connected to the system.

    Column Name Data Type Description
    workspace_id UUID (PK) Unique workspace identifier
    workspace_name VARCHAR Name of the Slack workspace
    slack_workspace_id VARCHAR Slack workspace identifier
    created_by UUID (FK) User who created the workspace
    created_at TIMESTAMP Creation timestamp

    Project Table¶

    Stores project information created by administrators.

    Column Name Data Type Description
    project_id UUID (PK) Unique project identifier
    project_name VARCHAR Name of the project
    description TEXT Project description
    workspace_id UUID (FK) Associated workspace
    created_by UUID (FK) User who created the project
    created_at TIMESTAMP Creation timestamp

    Project Channel Mapping Table¶

    Maps projects to Slack channels where communication occurs.

    Column Name Data Type Description
    mapping_id UUID (PK) Unique mapping identifier
    project_id UUID (FK) Associated project
    channel_id VARCHAR Slack channel ID
    channel_name VARCHAR Slack channel name
    created_at TIMESTAMP Mapping creation timestamp

    Channel Conversation Table¶

    Stores Slack messages from project channels.

    These messages are later processed by the Communication Intelligence module.

    Column Name Data Type Description
    message_id UUID (PK) Unique message identifier
    channel_id VARCHAR Slack channel ID
    thread_id VARCHAR Slack thread ID
    user_id UUID (FK) User who sent the message
    message_text TEXT Message content
    timestamp TIMESTAMP Message timestamp
    processed BOOLEAN Whether message has been processed by AI

    Tasks Table¶

    The Tasks table stores work items assigned to team members.
    These tasks are automatically extracted from Slack standup communication using the LLM.

    Column Name Data Type Description
    id UUID (PK) Unique identifier for the task
    content TEXT Description of the task
    sender_slack_id VARCHAR Slack ID of the user associated with the task
    project_id UUID (FK) Project to which the task belongs
    status VARCHAR Task status (Open, In Progress, Completed)
    priority VARCHAR Task priority (Low, Medium, High)
    created_at TIMESTAMP Time when the task was created
    updated_at TIMESTAMP Last update timestamp
    deleted_at TIMESTAMP Soft delete timestamp

    Blockers Table¶

    The Blockers table stores issues or obstacles reported by team members during development.

    These blockers are detected from Slack communication and tracked for resolution.

    Column Name Data Type Description
    id UUID (PK) Unique identifier for the blocker record
    content TEXT Description of the blocker
    sender_slack_id VARCHAR Slack ID of the user who reported the blocker
    project_id UUID (FK) Project associated with the blocker
    severity VARCHAR Severity level (Low, Medium, High, Critical)
    status VARCHAR Status of the blocker (Open, In Progress, Resolved)
    created_at TIMESTAMP Time when blocker was created
    updated_at TIMESTAMP Last update timestamp
    deleted_at TIMESTAMP Soft delete timestamp

    Daily Updates Table¶

    The Daily Updates table stores daily progress updates extracted from Slack standup communication.

    These updates help track team progress and project activity.

    Column Name Data Type Description
    id UUID (PK) Unique identifier for the update
    content TEXT Daily update content
    sender_slack_id VARCHAR Slack ID of the sender
    project_id UUID (FK) Associated project
    summary TEXT LLM-generated summary of the update
    created_at TIMESTAMP Update creation time
    updated_at TIMESTAMP Last update timestamp
    deleted_at TIMESTAMP Soft delete timestamp
