    Communication Intelligence Module¶

    1. Overview¶

    Build an AI Project Manager Bot for Slack that:

    • Conducts daily standups
    • Collects team updates
    • Uses an LLM to categorize updates into:
      • Tasks
      • Blockers
      • Daily Updates
    • Stores structured information in PostgreSQL
    • Provides an AI chatbot interface that answers project questions by querying the database.

    The chatbot interacts directly inside Slack channels.

    4. Daily Standup Workflow¶

    Step 1 -- AI PM Bot Posts Standup Message¶

    At 9:30 AM, the AI bot posts a standup prompt.

    Example:

    The following team members were assigned tasks:

    Aarushi → Task1

    Akshita → Task2

    Rudraksh → Task3

    Manav → Task4

    Please mention your updates in this thread.

    Slack returns:

    • channel_id
    • thread_ts (thread timestamp)

    This thread ID is stored.

    5. Thread Storage¶

    Standup Threads Table¶

    id channel_id thread_ts date

    1 C123 1712343434 2026-03-09

    All standup replies occur under this thread.

    6. Team Members Reply¶

    Example replies:

    Aarushi: Completed API integration. Working on testing. Blocker: waiting for DB schema

    Akshita: Finished UI design. Started frontend integration

    Slack sends events containing:

    • message text
    • thread_ts
    • user id

    7. Raw Message Storage¶

    standup_messages¶

    id user text thread_ts timestamp

    1 U01 completed api integration ts 10:00 2 U02 finished UI design ts 10:02

    These messages are processed later by the LLM.

    8. 10 AM Standup Processing¶

    At 10:00 AM, the backend collects all thread messages and sends them to the LLM.

    Example Input to LLM¶

    User: Aarushi

    Message: Completed API integration. Working on testing. Blocker: waiting for DB schema.

    User: Akshita

    Message: Finished UI design. Started frontend integration.

    9. LLM Categorization Prompt¶

    The LLM is asked to extract structured data.

    Example instruction:

    Return JSON in this format:

    { "Aarushi": { "tasks": "","blockers": "","daily_updates": "" }, "Akshita": { "tasks": "","blockers": "","daily_updates": "" } }

    12. AI Chatbot Architecture¶

    When a user asks a question in Slack:

    @ai-pm-bot What blockers does Aarushi have?

    Slack sends an app_mention event to the backend.

    13. Chatbot Processing Flow¶

    sequenceDiagram

participant User
participant Slack
participant Backend
participant LLM
participant Database

User->>Slack: Ask question
Slack->>Backend: Event API
Backend->>LLM: Send user query

LLM->>Backend: Tool call decision

Backend->>Database: Query data

Database->>Backend: Return results

Backend->>LLM: Provide tool result

LLM->>Backend: Final answer

Backend->>Slack: Send response

Slack->>User: Display message

    14. LLM Tool Calling¶

    The chatbot uses tools to query the database.

    Available tools:

    get_tasks(user_name)

    get_blockers(user_name)

    get_updates(user_name)

    Example Tool¶

    get_blockers("Aarushi")

    SQL Query:

    SELECT content FROM blockers JOIN users ON users.id = blockers.user_id WHERE users.name = 'Aarushi' AND status='open'

    15. Example Chat¶

    16. Slack Response¶

    Backend sends the response to Slack.

    Slack API:

    chat.postMessage

    Example request:

    { "channel":"C123", "thread_ts":"1712343434", "text":"Aarushi is currently working on API integration testing" }
